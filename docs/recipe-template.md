# Recipe Template

Use this template when adding a new recipe. Copy the structure below into a new file in the `recipes/` folder.

File naming convention: use lowercase with hyphens, e.g. `chocolate-cake.md`, `chicken-soup.md`

---

```markdown
# Recipe Name

**Category:** Breakfast | Lunch | Dinner | Snack | Drinks | Dessert
**Difficulty:** Easy | Medium | Hard
**Serves:** X
**Time:** X minutes

---

## Ingredients

- Item 1
- Item 2

---

## Instructions

1. Step one.
2. Step two.

---

## Tips

- Optional tips go here.
```

---

Once you've added your recipe file, also update the **Recipes table** in `README.md` to include your new recipe.
